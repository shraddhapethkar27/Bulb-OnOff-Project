# 💡 Bulb On/Off Project

A simple and interactive web application built with HTML, CSS, and JavaScript that demonstrates basic DOM manipulation. Users can switch a bulb ON and OFF through button clicks, showcasing how JavaScript dynamically updates webpage elements.

## Features

* Interactive Bulb ON/OFF functionality
* DOM Manipulation using JavaScript
* Clean and responsive user interface
* Beginner-friendly project structure

## Technologies Used

* HTML5
* CSS3
* JavaScript
